# RoboParty Lab

A personal index to selected public projects from the RoboParty GitHub
organization. Upstream repositories are the source of truth for code,
documentation, releases, issues, and license terms.

此仓库整理 RoboParty 公开项目的入口，方便按平台、软件模块和硬件资料查阅。项目代码与文档以 RoboParty 官方仓库为准；此处是个人索引，不代表 RoboParty 官方发布。

## Core projects

| Project | Focus | Official source |
| --- | --- | --- |
| **RP1** | RoboParty humanoid robot platform | [Roboparty/RP1](https://github.com/Roboparty/RP1) |
| **ROBOTO_ORIGIN** | Fully open-source DIY humanoid robot prototype | [Roboparty/roboto_origin](https://github.com/Roboparty/roboto_origin) |
| **Party_OS** | Humanoid system built by RoboParty Lab | [Roboparty/Party_OS](https://github.com/Roboparty/Party_OS) |
| **RP1 hardware** | Mechanical, electrical, PCB, and assembly materials | [Roboparty/RP1_hardware](https://github.com/Roboparty/RP1_hardware) |
